# Explainable AI-Driven Energy & Carbon Forecaster

A fully local, CPU-only pipeline for forecasting household energy consumption
and estimating carbon footprint using Indian smart meter data (Mathura 2020).

## Tech Stack
| Layer | Library |
|---|---|
| Data wrangling | pandas, numpy |
| ML model | XGBoost |
| Explainability | SHAP |
| Visualization | Plotly |
| Dashboard | Streamlit |

---

## Setup

```bash
# 1. Create & activate virtual environment
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

# 2. Install dependencies
pip install -r requirements.txt

# 3. Place raw CSVs in data/raw/

# 4. Run the dashboard
streamlit run app.py
```

## Running individual phases

```bash
# Phase 1 — verify data pipeline
python -m src.data_engineering

# Phase 2 — EDA charts
python -m src.eda_visualization

# Phase 3 — train XGBoost model
python -m src.modeling

# Phase 4 — SHAP explainability
python -m src.explainability
```
